# Python Quiz Application

This is a simple Python quiz application I built as a mini project while learning Python.

## Features
- Asks the player's name
- Displays multiple-choice questions
- Checks answers and calculates the score
- Shows the final percentage and feedback
- Saves quiz results in a JSON file
- Checks user input

## Python Concepts Used
- Variables and data types
- Lists, dictionaries and tuples
- Loops and conditional statements
- Functions and classes
- String methods
- Exception handling
- File handling and JSON

## How to Run
1. Install Python 3.
2. Download this repository.
3. Open a terminal in the project folder.
4. Run:

   `python main.py`

## What I Learned

I built this project to practise the Python concepts I learned during my first month of learning Python. It helped me understand how to combine these concepts into a working application.
